# Brief

**Goal:** one sentence.

**In scope:** files or directories the agent may change.

**Out of scope:** what it must not touch.

**Acceptance:** the exact command(s) that must pass, e.g. `npm test && npm run typecheck`.

**Context:** links to the issue, previous errors (verbatim), related PRs.

**Deliverable:** a draft PR with a short description of what changed and how it was verified.
